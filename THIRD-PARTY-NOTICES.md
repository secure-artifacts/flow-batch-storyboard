# Third-party notices

The deployable JavaScript bundles contain third-party frontend libraries. The available materials do not include the original dependency manifest or a complete software bill of materials, so exact package versions and license texts cannot be reconstructed reliably from this bundle alone.

Code inspection shows bundled components including React-related code, Ant Design-related UI code and Handsontable-related spreadsheet code. This list may be incomplete and is not a substitute for a formal dependency and license audit.

Before public distribution, the repository owner must identify all bundled dependencies, verify their versions and licenses, and add the required notices or commercial licenses. In particular, Handsontable licensing terms should be reviewed carefully.
