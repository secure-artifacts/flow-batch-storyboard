# Flow 批量生成 · 分镜表 3.0（Firefox）

## 适用环境

- 桌面版 Firefox 140 或更高版本。
- 已登录并可正常使用 Google Flow 的账号。
- 建议使用最新版 Firefox。

## 使用 ZIP 临时安装

1. 在 Firefox 地址栏打开 `about:debugging`。
2. 点击左侧“此 Firefox”。
3. 点击“临时载入附加组件”。
4. 选择 Firefox ZIP 包；也可以解压后选择根目录中的 `manifest.json`。
5. 打开或刷新 Google Flow 项目页面。

临时安装会在 Firefox 完全退出后失效，这是 Firefox 的安全机制。

## 使用 XPI 安装

- Firefox 正式版通常要求 XPI 经过 Mozilla 签名。
- 未签名 XPI 主要用于允许未签名扩展的测试环境。
- 如需长期安装，可将 Firefox ZIP 提交至 Mozilla Add-ons，选择不公开发布或自分发签名，再安装 Mozilla 返回的签名 XPI。

## 升级

1. 先停止正在运行的批量任务，并保存断点。
2. 移除旧的临时版本后，重新载入新版 ZIP 或 `manifest.json`。
3. 刷新 Google Flow 页面。
4. 不要同时启用多个版本。

## 使用前检查

- 确认 Google Flow 页面已登录且可手动生成视频。
- 确认图片、分镜名称和提示词已正确载入。
- 按需要设置目标轮数、每轮生成数量、提交间隔、随机时间、在途数和补跑轮数。
- 首次正式批量运行前，建议先用少量数据测试。
- 需要自动下载时，请允许 Firefox 下载多个文件。

## 注意事项

- 批量运行期间请保持 Google Flow 页面和浏览器开启。
- 提交间隔过短可能触发 Google Flow 的频率或异常活动限制，建议根据账号和服务状态适当调大间隔与随机时间。
- Google Flow 拒绝、限流或服务异常时，插件会按当前设置记录失败并继续处理后续任务；启用失败补跑后，会在后续轮次补跑未达标项目。
- 达到目标数量的行不会再次自动生成。
- 更换浏览器、浏览器用户资料或插件 ID 时，本地断点不会自动迁移；请先保存断点文件。
- 下载文件夹必须位于浏览器默认下载目录内。
- 插件只能辅助自动化操作，Google Flow 的额度、模型可用性、生成结果和服务限制由 Google 决定。

## 常见处理

- 看不到插件面板：确认插件已启用，然后刷新 Google Flow 页面。
- 更新后行为未变化：重新载入扩展，再刷新 Flow。
- 下载没有开始：检查 Firefox 下载权限和下载记录。
- 页面或任务异常：先停止继续提交，保存断点，刷新页面后恢复。
