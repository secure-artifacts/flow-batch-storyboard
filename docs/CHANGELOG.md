# 版本变更

## 2.3.26

- 修复 2～4 个输出被 Flow 分批返回时，收到第一个任务 ID 就提前判定其余输出失败的问题。
- 等待每个真实任务分别成功或失败，三分钟仍未结算才处理缺失项。
- 自动迁移 v2.3.25 的 `__flow_missing_` 假失败数据。
- 从断点中的真实任务 ID 恢复缺失结果地址，并保留已下载文件顺序以便只补下载。

## 2.3.25

- 将假“正在生成”任务的硬性保护时间调整为 180 秒。

## 2.3.24

- 修复断点提示恢复成功但表格为空的问题。
- 断点恢复后校验行数和关键字段确实进入表格。
- 保留旧断点中的已生成结果。

## 2.3.23

- 任务运行期间保护 Flow 标签页，减少无人值守时被浏览器丢弃。
- 加入休眠感知计时。
- 断点改用 Blob 下载，修复超长 `data:` URL 被拒绝。
- 加入 Chrome 保持运行和 Firefox Wake Lock 适配。

本审核仓库从 2.3.23 起保留与当前安全性、断点和无人值守功能相关的主要变更。
