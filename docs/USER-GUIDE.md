# 使用手册

## 基本流程

1. 在 Flow 中建立或打开一个集合。
2. 打开插件的分镜批量界面。
3. 粘贴或填写图片名、分镜名称和提示词。
4. 选择素材模式或帧模式。
5. 在 Flow 集合中上传对应图片。
6. 点击“加载素材/首帧图”，帧模式需要时再加载尾帧图。
7. 设置生成间隔、并发、模型、画幅和输出数量。
8. 点击“开始 / 继续未完成”。

## 输出数量

数量支持 1、2、3、4 个。Flow 可能分多次返回任务 ID，插件会持续汇总，直到每个输出成功、失败或超过三分钟仍未结算。

多输出文件按以下方式命名：

- `分镜名称-1.mp4`
- `分镜名称-2.mp4`
- `分镜名称-3.mp4`
- `分镜名称-4.mp4`

## 三分钟卡住保护

180 秒从该行真正提交给 Flow 的时间开始计算，不包含分镜之间的生成间隔。超过 180 秒仍未返回的缺失输出会被标记为失败，之后按照补跑设置处理。已经成功返回的视频不会丢失。

## 无人值守

- Chrome 运行期间会阻止任务标签页被自动丢弃，并申请保持系统运行但允许屏幕关闭。
- Firefox 会保护标签页，并在页面可见时申请唤醒锁。
- 系统主动关机、断网、浏览器崩溃或强制结束进程仍可能中断任务，长时间离开前建议保存断点。

## 下载失败

生成成功但下载失败时，结果会保留。刷新 Flow、确认登录状态和下载权限后，点击该行“下载”，不需要重新生成。

## 手动重生

“重生”会建立新一轮生成任务，并清空该行上一轮用于自动结算的结果记录。需要保留旧视频时，应先下载或保存断点。

## 使用断点

点击“保存断点到项目文件夹”导出 JSON。换浏览器或换集合后：

1. 上传图片。
2. 点击“上传 / 恢复断点”。
3. 重新加载素材图或首尾帧图。
4. 下载已恢复结果。
5. 点击“开始 / 继续未完成”。
